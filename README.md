# MindCure Backend (`mindcure_back`)

This folder contains the backend codebase for the MindCure application. It is a Node.js/TypeScript project using Express, Prisma ORM, and other modern backend technologies. The backend provides RESTful APIs, real-time socket communication, and integrations for the MindCure platform.

## Key Components

### Controllers

Located in `src/controllers/`, these files contain the business logic for each API domain:

- **appointments.controller.ts**: Handles appointment scheduling, retrieval, and management.
- **chat.controller.ts**: Manages direct chat messages between users.
- **therapist.controller.ts**: Therapist profile and related operations.
- **journal.controller.ts**: CRUD operations for user journals.
- **wallet.controller.ts**: Manages user wallets and transactions.
- **emotion.controller.ts**: Tracks and retrieves user emotions.
- **payment.controller.ts**: Payment processing and integration.
- **sessionNote.controller.ts**: Notes for therapy sessions.
- **chatbot.controller.ts**: AI chatbot interactions.

### Routes

Located in `src/routes/`, these files map HTTP endpoints to controllers:

- Each file (e.g., `appointments.routes.ts`, `chat.routes.ts`) defines the RESTful endpoints for its domain.
- Example: `appointments.routes.ts` maps `/appointments` endpoints to the appointments controller.

### Services

Located in `src/services/`:

- **db.ts**: Database connection logic.
- **redisService.ts**: Redis caching and pub/sub logic.

### Sockets

Located in `src/sockets/`:

- **socket.ts**: Main WebSocket server logic, handling real-time events.
- **chat.ts**: Real-time chat event handling.

### Utilities

Located in `src/utils/`:

- **callLogger.ts**: Logging for call events.
- **idMapper.ts**: Utility for mapping IDs.
- **logger.ts**: General logging utility.
- **flutterwave.ts**: Payment integration helpers.
- **createUser.ts**: User creation logic.
- **MentalHealthScenario.ts**: Mental health scenario utilities.
- **Scenario.ts**: Scenario modeling.
- **types.ts**: Utility types.

### Middleware

Located in `src/middleware/`:

- **verifyTherapist.ts**: Middleware to verify therapist status for protected routes.

### Types

Located in `src/types/`:

- **websocket.ts**: WebSocket type definitions.
- **flutterwave-node-v3.d.ts**: Payment provider types.
- **express/**: Express type extensions.

### Mediasoup

Located in `src/mediasoup/`:

- **handlers.ts**: Media server event handlers for calls.
- **server.ts**: Mediasoup server setup.

### Lib

Located in `src/lib/`:

- **prisma.ts**: Prisma client instance for database access.

### Generated

Located in `src/generated/`:

- **prisma/**: Auto-generated Prisma client code.

## Database

- **Prisma ORM** is used for database modeling and migrations.
- **schema.prisma** defines models such as `Profile`, `TherapistDetail`, `JournalEntry`, `Message`, `GroupChat`, `Session`, `Wallet`, `Transaction`, and more.
- **Migrations** are stored in `prisma/migrations/` and include:
  - `20250411100348_new_migration`: Initial schema.
  - `20250416134831_add_wallet_table`: Adds wallet support.
  - `20250423143554_add_txref_to_session`: Adds transaction reference to sessions.
  - `20250524091016_added_transactions`: Adds transaction model and logic.

### Example Models (from `schema.prisma`)

- **Profile**: Represents users (patients, therapists, admins) with fields for name, email, role, avatar, etc.
- **TherapistDetail**: Additional info for therapists (specialties, certifications, verification, etc.).
- **JournalEntry**: User journals, moods, tags, and sharing with therapists.
- **Message**: Direct messages between users, with status tracking.
- **GroupChat/GroupMember/ChatMessage**: Group chat support.
- **AIChat**: Stores AI chatbot interactions.
- **Session/SessionNote**: Therapy session scheduling and notes.
- **CallLog**: Logs for voice/video calls.
- **Notification**: User notifications (messages, reminders, etc.).
- **Wallet/Transaction**: User wallet and transaction records.

## Getting Started

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Set up environment variables:**  
   Create a `.env` file with the required configuration (database URL, secrets, etc.).

3. **Run database migrations:**
   ```bash
   npx prisma migrate deploy
   ```

4. **Start the development server:**
   ```bash
   npm run dev
   ```

5. **Run tests:**
   ```bash
   npm test
   ```
